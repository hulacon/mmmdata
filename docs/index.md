# Multi-Modal Memory Dataset (MMMData)

A dense fMRI study investigating how the brain remembers sights and sounds
across traditional experimental and naturalistic settings, conducted at the
University of Oregon.

## The dataset

### [Dataset Description](doc/dataset-description)

Study design, experimental tasks, stimuli, MRI acquisition parameters, BIDS
file organization, and preprocessing pipelines. Start with the
[Study Overview](doc/shared/study-overview) for a high-level summary.

### [Access](doc/shared/access)

Information on data availability and how to request access.

### [Contributors](doc/shared/contributors)

Project team and institutional affiliations.

## Working with the code

### [Code & Tools](doc/code-and-tools)

For people running the [mmmdata](https://github.com/hulacon/mmmdata) code
against a copy of the dataset: QC review guidance, attaching Claude through
the MCP server, API documentation generated from the packages' docstrings,
and guides to command-line tools such as `mmmview`.
