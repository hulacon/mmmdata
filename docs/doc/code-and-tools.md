# Code & Tools

The [Dataset Description](dataset-description) describes the data. This
section is for people **running the mmmdata code** against a copy of it:
converting, reviewing quality, querying, and plotting.

- [QC Review Guidance](qc-guidance) — what each image-quality metric
  measures, how runs get flagged, and how to review one.
- [Claude and the MCP Server](claude-and-mcp) — attaching an AI agent to
  your copy of the dataset.
- [Code Documentation](code/code_index) — API reference for the Python
  packages, generated from their docstrings on every deploy.
- [Tools](code/tools_index) — guides to the command-line tools, such as
  `mmmview`.
